# RootMC Marketing

RootMC deployment checklist and **paste-ready copy** for listings, votes, Reddit, Discord, social, and events.

**Generic templates (any server):** [Minecraft-Marketing](https://github.com/RootRecord/Minecraft-Marketing)

---

## Quick start

1. **Checklist:** [ROOTMC-MARKETING-DEPLOYMENT.md](ROOTMC-MARKETING-DEPLOYMENT.md)  
2. **Paste now:** [copy/master-fields.md](copy/master-fields.md) + platform doc below  
3. **When vote IDs / version change:** [templates/updatable-values.md](templates/updatable-values.md) only — then sync plugin/site config
